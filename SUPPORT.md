# Getting help

- Use [GitHub Discussions](https://github.com/heyo-sh/heyo-ui/discussions) for
  questions, integration help, and early design conversations.
- Use an issue template for confirmed bugs and well-defined feature requests.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

Before posting, please check the [README](README.md) — the design rules explain
why components look and behave the way they do, and the deliberate non-features
explain what is missing on purpose — along with existing discussions and issues.

Never post secrets, access tokens, private API schemas, or customer data.
